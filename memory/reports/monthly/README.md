# Monthly Reports

**Directory**: Store monthly performance reports here
**Format**: YYYY-MM-report.md

## Report Contents

1. **Executive Summary** - Key wins and challenges
2. **Traffic Metrics** - Sessions, users, pageviews
3. **Keyword Rankings** - Hero + secondary keyword positions
4. **Backlinks** - New links acquired
5. **Content Performance** - Top performing pages
6. **Lead Generation** - Leads captured, sources
7. **Next Month Priorities** - Action items
