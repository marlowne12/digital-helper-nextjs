**Directory**: Store domain audits here
**Format**: YYYY-MM-DD-cite-audit.md

## Expected Audits

- Initial CITE audit
- Monthly domain health checks
- Post-update audits (after Google core updates)

## Audit Naming Convention

- `2026-02-18-initial-cite-audit.md`
- `2026-03-18-monthly-cite-audit.md`
- `2026-04-15-post-update-audit.md`

## CITE Dimensions

1. **Credibility** - Trust signals, reviews, testimonials
2. **Authoritativeness** - Backlinks, mentions, expertise
3. **Trust** - Security, privacy, contact info
4. **Expertise** - Content depth, author credentials
