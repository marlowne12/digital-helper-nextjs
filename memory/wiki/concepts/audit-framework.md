# Audit Framework

## Overview
The project already defines a repeatable audit system across technical SEO, content quality, domain authority/CITE, and backlinks.
Even though the audit directories currently look template-like, they reveal the intended operating cadence and scorecards.

## Audit categories
### Technical audits
Focus areas:
- site speed and Core Web Vitals
- crawlability and index coverage
- schema markup
- mobile usability
- local SEO technical elements such as NAP consistency

### Content audits
Focus areas:
- homepage and service page quality
- blog and location page coverage
- CORE-EEAT scoring
- trust, expertise, and conversion signal quality

### Domain / CITE audits
Focus dimensions:
- credibility
- authoritativeness
- trust
- expertise

### Backlink audits
Focus areas:
- total backlink count
- domain diversity
- local and industry relevance
- toxic-link review
- competitor backlink comparisons

## Strategic value
Together these audits form the quality-control layer of the growth system.
They connect execution details to the project's larger goals around rankings, authority, and conversion readiness.
