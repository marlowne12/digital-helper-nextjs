# HEARTBEAT.md - Low-Touch Work Cycles

This workspace should not run automatic heartbeats unless Mars explicitly asks for automation.

Use this file as the manual operating rhythm when Mars returns to the workspace.

## Manual Cycle

1. Read `tasks/NEXT_ACTIONS.md`.
2. Pick the highest-priority unblocked item.
3. Do one small chunk.
4. Update the daily log.
5. Update the task queue.

## If Automation Is Later Approved

Use a low-cost, wake-on-demand model:

- No background monitoring by default.
- No public posting.
- No account actions.
- No recurring token spend without a clear budget.
- One atomic work chunk per wake.

## Suggested Manual Rotation

- Offer: improve the live paid offer or buyer path.
- Distribution: prepare one approved post, comment, or DM.
- Evidence: document buyer questions, objections, or responses.
- Cleanup: make the next session easier.

## Empty Queue Response

If there is nothing useful to do, say:

```text
HEARTBEAT_OK - no unblocked workspace tasks.
```
