## 🚀 How to Invoke

### Auto-invocation
Claude Code will automatically invoke an agent when your prompt contains its trigger keywords (listed in each agent's `description` frontmatter). Example prompts:

| Prompt | Likely agent |
|--------|--------------|
| "Add a new field to the audit report PDF" | `geo-audit-specialist` |
| "Give me a keyword strategy for Kennewick plumbers" | `tri-cities-local-seo-strategist` |
| "Swap the chat model to gemini-2.5-pro" | `gemini-ai-integrator` |
| "The contact form is throwing 500s" | `supabase-lead-engineer` |
| "Add a review velocity widget to the reputation dashboard" | `reputation-dashboard-dev` |

### Explicit invocation
```
@geo-audit-specialist please audit the PDF generation flow
```

## 🔗 Typical Workflows

### 🟢 Workflow 1: Ship a new GEO Audit feature
```
1. tri-cities-local-seo-strategist → content brief + target keywords
2. gemini-ai-integrator            → design prompt + model choice
3. geo-audit-specialist            → implement end-to-end flow
4. supabase-lead-engineer          → wire lead capture
5. code-reviewer                   → sequential review (Claude Code default)
```

### 🔵 Workflow 2: Campaign planning (no code changes)
```
1. tri-cities-local-seo-strategist → campaign brief + keyword prioritization
   (strategic agents are parallel-safe — can run alongside frontend-design discussions)
```

### 🟢 Workflow 3: New reputation widget
```
1. reputation-dashboard-dev   → build widget + Places API integration
2. gemini-ai-integrator       → (if AI-powered) tune the prompt
3. code-reviewer              → review
```

### 🟢 Workflow 4: Emergency — leads not capturing
```
1. supabase-lead-engineer → debug degradation ladder (Supabase → log → Resend)
2. code-reviewer          → validate fix
```

## ⚙️ Coordination with Existing `.agent/agents/`

This project already has **20 generic agents** in `.agent/agents/` (backend-specialist, frontend-specialist, seo-specialist, etc.). The new `.claude/agents/` set is **project-specific and complementary**:

| When to use `.agent/` generic | When to use `.claude/` custom |
|-------------------------------|-------------------------------|
| Generic React patterns, styling | Digital Helper theme + Electric Midnight utilities |
| Standard SEO best practices | Tri-Cities-specific keyword + campaign data |
| Generic backend patterns | Digital Helper's specific degradation ladder |
| Generic AI integration | Project's exact Gemini model matrix + env fallbacks |

**Rule of thumb**: Try a `.claude/` custom agent first for Digital Helper work; fall back to `.agent/` generics when the task is truly generic.

## 📦 Installation

These files live in `.claude/agents/` (project-scoped). They're automatically discovered by Claude Code when working in this repo. To make any of them available globally, copy to `~/.claude/agents/`:

```bash

```
