# Digital Helper 3D Asset Pack

This pack contains prompt-ready creative direction and a small Remotion project for rendering Digital Helper 3D-style website assets.

## Asset Concepts

- **AI Website Engine**: a premium 3D website dashboard/laptop system for homepage and web design pages.
- **Local SEO Signal Map**: a Tri-Cities local search visibility scene for SEO and location pages.
- **Automation Workflow Core**: connected workflow nodes for AI automation and lead generation pages.

## Files

- `PROMPTS.md`: Copy-ready image and video prompts using the 3D asset prompt workflow.
- `prompts.html`: Browser-friendly prompt page with tabs and copy buttons.
- `remotion/`: Renderable Remotion project for animated 3D-style assets.
- `renders/`: Output folder for stills and videos.

## Remotion Commands

Run these from `creative/digital-helper-3d-assets/remotion`:

```bash
npm install
npm run studio
npm run stills
npm run render
```

The render scripts output files into `../renders/`.
