# Digital Helper First Client Acquisition Hub

This folder is the working hub for getting Digital Helper its first client.
It is not a generic marketing plan. It is the operating folder for what to do next, what Paperclip agents should help with, and what Mars should execute manually.

## Goal

Win the first paid Digital Helper client from a Tri-Cities local business.

Primary offer:

> Free website and Google visibility audit. If there is a clear win, Digital Helper can fix one high-impact thing for $497, then quote the full rebuild or SEO package after trust is earned.

## Current Focus

1. Pick 10 strong local prospects from the existing lead lists.
2. Manually verify each prospect still has a weak or missing web presence.
3. Create one useful observation for each prospect.
4. Send or call with a value-first audit offer.
5. Track every response and follow up within 48 hours.

## Rules

- Do not chase every idea at once.
- Do not build more automation until the first manual client path is proven.
- Do not send generic agency copy.
- Every outreach message needs one real observation about that business.
- Track every touch, even if there is no response.
- Use `(509) 987-5060` as the only phone number in outreach.

## Success Criteria

Week one is successful if:

- 10 prospects are verified.
- 10 personalized first touches are sent.
- 5 follow-ups are scheduled or completed.
- At least 1 discovery call is booked.

The first-client milestone is complete when a prospect pays a deposit or buys the $497 starter fix.
