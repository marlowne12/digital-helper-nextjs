# Solo Operator Plan

This plan assumes Mars works full time in a warehouse and cannot babysit the agency all day.

The agency system should only ask Mars to do the parts agents cannot do well:

- make the actual call
- reply like a real local business owner
- approve offers and pricing
- collect payment

Everything else should be prepared by agents.

## Daily Time Budget

Minimum: 20 minutes on work days.

| Time | Action |
| --- | --- |
| 5 min | Check Paperclip project `First Client Acquisition` |
| 5 min | Pick the best prepared prospect |
| 5 min | Send one prepared email or text |
| 5 min | Make one call or follow up one warm lead |

If there is extra energy, do more. If not, the day is still a win if one real touch happened.

## Weekly Time Budget

One deeper block on a day off: 60 to 90 minutes.

Use that block for:

1. Review all Paperclip-prepared prospects.
2. Send 5 prepared messages.
3. Call the top 5.
4. Send the $497 starter-fix offer to anyone warm.
5. Update `daily-tracker.md`.

## Agent Division Of Labor

| Work | Owner |
| --- | --- |
| Find and score prospects | CMO / Hermes when connected |
| Draft first-touch messages | CMO |
| Verify website/contact path | Codex CEO / Claude once hooked up |
| Build/fix site assets | Claude Code once hooked up |
| Keep issues organized | Codex CEO |
| Calls, replies, close | Mars |

## Mars' Only Required Daily Script

```text
I only need to do one real business-development action today.

The agents can prepare the research.
My job is to contact one real person and ask for the next step.
```

## What Not To Do

- Do not try to learn every marketing skill first.
- Do not rebuild the whole site before contacting people.
- Do not wait until Hermes and Claude are perfect.
- Do not send 50 generic messages.
- Do not work until burnout after a warehouse shift.

## First 7 Work Days

| Day | Mars Action | Agent Action |
| --- | --- | --- |
| 1 | Send 1 prepared outreach message | CMO prepares next 5 |
| 2 | Call 1 high-priority prospect | CMO scores next batch |
| 3 | Follow up prior message | Codex checks blockers |
| 4 | Send 1 starter-fix offer if any warm reply | CMO drafts proposal |
| 5 | Call 1 more prospect | Agents prepare next week list |
| 6 | Review all replies | Codex updates tracker |
| 7 | Send 5 messages during day-off block | Agents prepare follow-ups |

The goal is consistency, not volume.

## First Client Target

Get one person to say yes to:

> A $497 starter fix that solves one missed-lead problem.

That is enough to prove the agency can sell.
