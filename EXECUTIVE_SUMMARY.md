   - 50+: Option A is essential

2. **Do you have a CRM preference?**
   - No preference: Use HubSpot (easiest)
   - Already using one: We'll integrate with it
   - Want to avoid monthly fees: We can build lightweight CRM

3. **What's your biggest pain point right now?**
   - Losing leads → Start with Phase 1
   - Slow follow-up → Start with Phase 2
   - Manual admin → Start with Phase 3
   - Client communication → Start with Phase 4

4. **Do you have a team or solo?**
   - Solo: Focus on automation (Phases 1, 2, 5)
